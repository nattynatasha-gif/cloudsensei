# CloudSensei

Your AI Study Buddy for the Microsoft AZ-900 Exam

CloudSensei is a warm and encouraging study companion that helps you learn Azure concepts through original practice questions, clear feedback, interactive flashcards, and simple progress tracking.

Built for the Power Learn Project Africa – Vibe Coding Hackathon: AZ-900 Exam Prep Edition

## Live Demo
https://cloudsensei-az900.lovable.app/

## Features
- Original practice questions with immediate smart feedback (correct answer + explanation)
- Interactive flashcards
- Progress tracking based on real quiz performance (informal study indicator only)
- Supportive learning experience
- Fully responsive design

## Tech Stack
- Lovable
